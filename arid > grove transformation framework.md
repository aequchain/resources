PHASE 1: PURPOSE CRYSTALLIZATION
Core Purpose

Design a self-sustaining polyculture grove system for South African arid/semi-arid conditions that transforms degraded land into productive food forests through a single optimized establishment event, requiring minimal intervention after Year 1, while maximizing yield diversity, water retention, shade provision, and habitat creation.
Success Criteria
Criterion	Measurement	Target
Establishment Success	Germination + survival rate	≥80% of planted positions viable
Food Diversity	Distinct food species producing	≥20 species by Year 3
Water Capture	Rainfall retained on-site	≥90% of precipitation
Shade Development	Canopy coverage	≥60% by Year 5
Self-Sustainability	External inputs required	Zero after Year 2
Yield Timeline	First harvest	Year 0 (vegetables), scaling annually
Scalability	Unit replication	Infinite tessellation
Optimal Definition

BEST = Maximum food output diversity × Maximum establishment certainty × Minimum ongoing intervention × Maximum resilience
PHASE 2: CONSTRAINT MAPPING
Immutable Constraints
Constraint	Implication	Design Response
South African climate variability	Must work 250-1000mm rainfall	Zone-adapted species selection
Gravity	Water flows downhill	Contour swale water harvesting
Plant biology	Different growth rates/needs	Succession guild design
Arid conditions	Limited water	Maximize capture + drought-tolerant species
Fire risk	Common in many SA regions	Firebreaks + coppicing species
Liberation Zones
Convention	Liberation Opportunity
"Irrigation required"	→ Rainwater harvesting eliminates need
"Regular weeding needed"	→ Dense polyculture self-suppresses weeds
"Separate orchards and gardens"	→ Integrated food forest maximizes synergy
"One species per row"	→ Guild planting maximizes mutual benefit
PHASE 3: THE OPTIBEST GROVE CELL
Core Innovation: The Swale-Guild Cell

A modular 200m² (10m × 20m) unit containing:

    Water harvesting infrastructure (swale + berm)
    Seven-layer food forest guild
    Protective barrier perimeter
    Integrated access paths

Layer 4 - HERB:        Annual vegetables, rapid establishment, soil coverage
Layer 5 - GROUND:      Living mulch, moisture retention, weed suppression
Layer 6 - ROOT:        Underground food storage, soil structure improvement
Layer 7 - VINE:        Vertical space utilization, canopy integration

        Strategy: Enhanced water harvesting, drought-tolerant species
        
ZONE C: SUB-HUMID (600-800mm annual rainfall)
        Eastern margins, Mpumalanga, coastal transitions
        Strategy: Standard water harvesting, broader species palette
        
ZONE D: HUMID (800-1200mm annual rainfall)
        KwaZulu-Natal coast, Eastern Cape coast, Tsitsikamma
        Strategy: Drainage management, maximum productivity species

┌─────────────────────────────────────────────────────────────────────────────┐
│ ESTABLISHMENT SUPPORT PROCEDURE │
├─────────────────────────────────────────────────────────────────────────────┤
│ │
│ TIMING: Week 1-6 after seeding │
│ INTENSITY: Decreasing over time (daily → weekly → monthly) │
│ PURPOSE: Ensure successful germination, address critical failures │
│ │
│ ═══════════════════════════════════════════════════════════════════════════│
│ │
│ WEEK 1: DAILY MONITORING (Days 1-7) │
│ ───────────────────────────────────────────────────────────────────────── │
│ │
│ □ DAY 1-2: Verify soil moisture │
│ • If surface dry and no rain expected, light water broadcast zone │
│ • If cracks forming, water immediately │
│ • Check swale holding water from rain (should infiltrate within 24-48hr) │
│ │
│ □ DAY 3-5: First germination check │
│ • Expected first emergers: Cowpea, millet, sorghum, morogo │
│ • Look for green shoots breaking surface │
│ • If nothing visible by Day 5 AND no rain since seeding, consider: │
│ - Light watering if soil very dry │
│ - Wait for rain (seeds viable in soil for weeks) │
│ │
│ □ DAY 5-7: Vegetative establishment check │
│ • Cassava: Buds should be swelling if moisture adequate │
│ • Sweet potato: New leaves should be visible │
│ • Aloe/Opuntia: Should be firm (not shriveled or rotting) │
│ │
│ PROBLEM DIAGNOSIS - WEEK 1: │
│ ┌────────────────────────────────────────────────────────────────────┐ │
│ │ SYMPTOM │ LIKELY CAUSE │ ACTION │ │
│ ├────────────────────────────────────────────────────────────────────┤ │
│ │ No germination, soil dry │ Insufficient water│ Water lightly │ │
│ │ No germination, soil moist │ Too soon - wait │ Check Day 7-10 │ │
│ │ Patchy germination │ Uneven seeding │ Normal - wait │ │
│ │ Seeds visible on surface │ Rain washed out │ Rake lightly │ │
│ │ Cassava cutting soft │ Rot (too wet) │ Replace if spare │ │
│ │ Sweet potato wilting │ Transplant shock │ Shade, water │ │
│ │ Opuntia soft/mushy │ Rot (not cured) │ Remove, replace │ │
│ └────────────────────────────────────────────────────────────────────┘ │
│ │
│ ═══════════════════════════════════════════════════════════════════════════│
│ │
│ WEEK 2: EVERY 2-3 DAYS MONITORING (Days 8-14) │
│ ───────────────────────────────────────────────────────────────────────── │
│ │
│ □ GERMINATION STATUS CHECK: │
│ │
│ Expected by Day 14: │
│ ┌────────────────────────────────────────────────────────────────────┐ │

│ ═══════════════════════════════════════════════════════════════════════════│
│ PROBLEM: Poor or no germination of broadcast seeds │
│ ═══════════════════════════════════════════════════════════════════════════│
│ │
│ DIAGNOSIS: │
│ ┌────────────────────────────────────────────────────────────────────────┐ │
│ │ SYMPTOM │ LIKELY CAUSE │ │
│ ├────────────────────────────────────────────────────────────────────────┤ │
│ │ No germination, soil dry │ Seeded before rain, insufficient water │ │
│ │ No germination, soil wet │ Seeds rotted (too wet) or eaten │ │
│ │ Patchy germination │ Uneven seed distribution │ │
│ │ Germination then death │ Damping off (fungal), or drought │ │
│ │ Seeds visible on surface │ Not incorporated, or rain washed up │ │
│ └────────────────────────────────────────────────────────────────────────┘ │
│ │
│ SOLUTIONS: │
│ • If before Week 2: Wait - seeds may still germinate │
│ • If Week 2-4 and dry: Water lightly, wait │
│ • If Week 4+ and failed: Reseed bare areas with fresh seed │
│ • Future prevention: Seed immediately after confirmed rain │
│ │
│ ═══════════════════════════════════════════════════════════════════════════│
│ PROBLEM: Tree seeds not germinating │
│ ═══════════════════════════════════════════════════════════════════════════│
│ │
│ DIAGNOSIS: │
│ ┌────────────────────────────────────────────────────────────────────────┐ │
│ │ SPECIES │ NORMAL GERMINATION │ IF NO GERMINATION │ │
│ ├────────────────────────────────────────────────────────────────────────┤ │
│ │ Moringa │ 7-21 days │ Seed may have been old │ │
│ │ Acacia/Faidherbia │ 14-45 days │ Treatment may have failed │ │
│ │ Fig │ 14-30 days │ Seeds too deep (need light)│ │
│ │ Guava │ 14-30 days │ Cold temperatures │ │
│ │ Pomegranate │ 30-60 days │ Pulp not cleaned properly │ │
│ │ Kei apple │ 30-90 days │ Hard seed coat │ │
│ │ Natal plum │ 14-30 days │ Seed not fresh │ │
│ └────────────────────────────────────────────────────────────────────────┘ │
│ │
│ SOLUTIONS: │
│ • Week 0-4: Wait - many tree seeds slow │
│ • Week 4+, Moringa: Replant with fresh seed │
│ • Week 4+, N-fixers: Re-treat with hotter water, replant │
│ • Week 6+, all: Consider transplanting nursery seedling if available │
│ • Future prevention: Use freshest possible seed, proper treatment │
│ │
│ ═══════════════════════════════════════════════════════════════════════════│
│ PROBLEM: Cassava cuttings rotting or failing │
│ ═══════════════════════════════════════════════════════════════════════════│
│ │
│ DIAGNOSIS: │
│ ┌────────────────────────────────────────────────────────────────────────┐ │
│ │ SYMPTOM │ LIKELY CAUSE │ │
│ ├────────────────────────────────────────────────────────────────────────┤ │
│ │ Cutting soft and mushy │ Rot from waterlogging or damage │ │
│ │ Cutting dried and shriveled │ Dried out before rooting │ │
│ │ No bud development │ Cutting too old, or upside down │ │
│ │ Buds start then die │ Rot at base, or pest damage │ │
│ └────────────────────────────────────────────────────────────────────────┘ │
│ │
│ SOLUTIONS: │
│ • If rotted: Remove, replace with fresh cutting in new position │
│ • If dried: Too late - replace with fresh cutting │
│ • If no buds: Check orientation (buds point UP), replace if wrong │
│ • Future prevention: Fresh cuttings, plant same day, correct depth │
│ │
│ ═══════════════════════════════════════════════════════════════════════════│
│ PROBLEM: Opuntia or Aloe rotting │
│ ═══════════════════════════════════════════════════════════════════════════│
│ │
│ DIAGNOSIS: │
│ Soft, mushy, black/brown discoloration = Rot │
│ │
│ CAUSE: │
│ • Opuntia: Not cured before planting (must dry 5-7 days) │
│ • Aloe: Planted too deep, or soil waterlogged │
│ • Both: Planted in standing water area │
│ │
│ SOLUTIONS: │
│ • Remove rotted material (don't compost - spreads disease) │
│ • Replace with properly cured material │
│ • If position waterlogged: Move to better drained location │
│ • Future prevention: Cure all succulents, don't overwater │
│ │
│ ═══════════════════════════════════════════════════════════════════════════│
│ PROBLEM: Swale not holding water │
│ ═══════════════════════════════════════════════════════════════════════════│
│ │
│ DIAGNOSIS: │
│ ┌────────────────────────────────────────────────────────────────────────┐ │
│ │ SYMPTOM │ LIKELY CAUSE │ │
│ ├────────────────────────────────────────────────────────────────────────┤ │
│ │ Water flows out end │ Not level, or end lower than start │ │
│ │ Water bypasses swale │ Not on contour, or upslope diversion │ │
│ │ Water drains instantly │ Very sandy soil, no infiltration │ │
│ │ Water stands for days │ Clay soil, poor drainage │ │
│ └────────────────────────────────────────────────────────────────────────┘ │
│ │
│ SOLUTIONS: │
│ • If flowing out end: Add check dam at end, or deepen end section │
│ • If bypassing: Re-survey contour, adjust swale position │
│ • If draining too fast: Line bottom with clay or add organic matter │
│ • If standing too long: Create overflow channel, or add sand │
│ │
│ ═══════════════════════════════════════════════════════════════════════════│
│ PROBLEM: Pest damage │
│ ═══════════════════════════════════════════════════════════════════════════│
│ │
│ COMMON PESTS: │
│ ┌────────────────────────────────────────────────────────────────────────┐ │
│ │ PEST │ DAMAGE │ CONTROL │ │
│ ├────────────────────────────────────────────────────────────────────────┤ │
│ │ Cutworm │ Seedlings cut at base │ Collar plants with │ │
│ │ │ overnight │ cardboard, handpick │ │
│ │ │ │ at night │ │
│ ├────────────────────────────────────────────────────────────────────────┤ │
│ │ Aphids │ Clustered on new growth, │ Spray with soapy │ │
│ │ │ leaves curling │ water, encourage │ │
│ │ │ │ ladybugs │ │
│ ├────────────────────────────────────────────────────────────────────────┤ │
│ │ Snails/slugs │ Holes in leaves, slime │ Remove mulch near │ │
│ │ │ trails │ affected plants, │ │
│ │ │ │ ash barrier │ │
│ ├────────────────────────────────────────────────────────────────────────┤ │
│ │ Ants │ Seeds carried away, │ Ash barrier, boiling │ │
│ │ │ aphid farming │ water on nest │ │
│ ├────────────────────────────────────────────────────────────────────────┤ │
│ │ Rodents │ Seeds and seedlings │ Deeper planting, │ │
│ │ │ eaten │ owl perches nearby │ │
│ ├────────────────────────────────────────────────────────────────────────┤ │
│ │ Birds │ Seeds scratched up │ Mulch thicker, │ │
│ │ │ │ scarecrow │ │
│ └────────────────────────────────────────────────────────────────────────┘ │
│ │
│ GENERAL PEST PRINCIPLES: │
│ • Diversity reduces damage (pests can't devastate everything) │
│ • Healthy plants resist pests better │
│ • Some damage acceptable - only act if >30% damage │
│ • Chemical pesticides NOT recommended (harm beneficial insects) │
│ │
│ ═══════════════════════════════════════════════════════════════════════════│
│ PROBLEM: Trees surviving but not growing │
│ ═══════════════════════════════════════════════════════════════════════════│
│ │
│ DIAGNOSIS: │
│ ┌────────────────────────────────────────────────────────────────────────┐ │
│ │ SYMPTOM │ LIKELY CAUSE │ │
│ ├────────────────────────────────────────────────────────────────────────┤ │
│ │ Yellow leaves │ Nitrogen deficiency │ │
│ │ Purple leaves │ Phosphorus deficiency │ │
│ │ Stunted with small leaves │ Competition, drought, or poor soil │ │
│ │ Wilting in daytime │ Root damage or drought │ │
│ │ Healthy but small │ Establishing roots (normal Year 1) │ │
│ └────────────────────────────────────────────────────────────────────────┘ │
│ │
│ SOLUTIONS: │
│ • Yellow leaves: Add more chop-drop from legumes around tree │
│ • Purple leaves: Add bone meal or wood ash around tree │
│ • Competition: Clear 50cm radius, add mulch │
│ • Drought: Water deeply (50L) weekly during establishment │
│ • Normal small: Wait - trees focus on roots Year 1 │
│ │
│ ═══════════════════════════════════════════════════════════════════════════│
│ PROBLEM: Fire damage │
│ ═══════════════════════════════════════════════════════════════════════════│
│ │
│ IF FIRE OCCURS: │
│ 1. Do NOT clear burned material immediately │
│ 2. Wait 2-4 weeks for regrowth │
│ 3. Many species will coppice (regrow from base) │
│ 4. Only remove clearly dead plants │
│ │
│ SPECIES THAT COPPICE AFTER FIRE: │
│ • Moringa (usually) │
│ • Acacia (definitely) │
│ • Fig (usually) │
│ • Pigeon pea (usually) │
│ • Cassava (definitely - regrows from roots) │
│ │
│ PREVENTION: │
│ • Maintain paths as firebreaks (keep clear of dry material) │
│ • Create 3m cleared strip around cell perimeter if fire-prone area │
│ • Barrier species (especially Euphorbia) help slow fire │
│ • Swale acts as natural firebreak │
│ │
